# Questlog 🎯

**Your Daily Quests, tracked offline.**

Questlog is a standalone desktop app for tracking your daily habits and quests. It runs entirely offline—your data is stored locally on your machine.

> **Note:** This is a closed-source project. All rights are reserved.

---

## 🚀 Features

- **Fully Offline & Private:** Your data lives in a local JSON file on your computer. No cloud, no accounts.
- **Streak Tracking:** Tracks active streaks and alerts you when they are "At Risk".
- **Visual Charts:** View your progress over 7, 14, or 30 days with bar charts, plus a 12-week "heatmap" graph.
- **Date Support:** Works with both Gregorian and Hejri Shamsi (Jalali) calendars.
- **Customizable UI:** Switch between 11 dark/light themes (Nightfall, True Dark, Aurora, Dracula, etc.) and choose between List, Grid, or Compact layouts.
- **Windows System Tray:** Minimize to tray, close to tray, or start minimized on boot.

---

## 💻 Installation (Portable)

Questlog is fully portable. No installation is required.

1. Download the latest `questlog.zip` from the **[Releases page](https://github.com/actually-aloy/questlog/releases)**.
2. Extract the zip file to any folder on your PC.
3. Run `Questlog.exe` to launch the app.

---

## 💾 Data & Backups

Your quest history is saved inside a `questlog_data.json` file located in the same folder as the `.exe`.

To backup or migrate your data, you have two options:
- **Using the GUI:** Open the app and click the **"Save backup (.json)"** or **"Restore backup"** buttons located in the stats section.
- **Manually:** Simply copy the `questlog_data.json` file to a safe place, or drop a saved backup back into the app folder to replace it.
